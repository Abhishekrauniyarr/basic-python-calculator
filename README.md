# Basic Python Calculator

A simple function-based calculator built using Python. This project was created to practise Python fundamentals and understand how functions, loops, conditionals, and exception handling work together.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Division-by-zero handling
- Input validation
- Continuous calculations using a loop
- Option to exit the calculator

## Technologies Used

- Python 3
- Built-in Python functions

## How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/Abhishekrauniyarr/basic-python-calculator.git
   ```

2. Navigate to the project directory:

   ```bash
   cd basic-python-calculator
   ```

3. Run the calculator:

   ```bash
   python main.py
   ```

## Concepts Practised

- Functions
- While loops
- If-elif-else statements
- Try-except exception handling
- Break and continue statements
- User input and type conversion
